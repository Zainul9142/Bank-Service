Slide 01 // Executive Presentation

Bank NumberShield: Automated Telecom SIM Recycling Protection

A next-generation banking security platform preventing account takeover fraud caused by recycled mobile numbers.

🚨 The Problem

Telecom operators recycle inactive phone numbers after 90 days. When reallocated, new SIM holders receive confidential banking OTPs and access to previous subscribers' bank accounts.

🛡️ The Solution

Automated 1-hour SLA phone number deregistration, Aadhaar Vault alternate contact discovery, AI fraud velocity scanner, and dual-portal customer recovery architecture.

Target: Executive Board & CISO
Slide 02 // Problem Breakdown

The Recycled Mobile SIM Vulnerability

📱 Telecom Recycling Reality

  • Over 15 million mobile numbers are recycled annually by telecom operators.
  • 68% of bank customers fail to update their primary mobile number when changing SIMs.
  • New SIM holders unknowingly inherit access to SMS banking alerts and password resets.

⚠️ Financial & Regulatory Impact

  • Account Takeovers: Fraudulent password resets & wire transfers.
  • UPI Hijacking: Automated UPI payment binding to recycled SIMs.
  • Non-Compliance: Violates RBI Cybersecurity Guidelines & PCI-DSS 4.0 standards.
Slide 03 // Solution Architecture

Core Operating Principles

1. Automated Real-Time Ingestion

Continuous background listener ingesting telecom SIM allocation & Aadhaar verification events in real-time.

2. Strict 1-Hour SLA Deregistration

Deactivates SMS OTP dispatch, UPI handles, and mobile banking access within 60 minutes of new SIM activation.

3. Aadhaar Vault Outreach

Queries bank CKYC & Aadhaar Data Vault to find verified alternate contacts without needing manual user API consents.

4. Security Restrict Mode

Automatically freezes high-value outbound transfers and locks debit/credit cards until identity is re-verified.

Dual Portal Architecture

📱 Customer Recovery Portal

/customer-login.html

  • Session Self-Destruct: Access permanently revoked upon exit.
Slide 05 // Technical Implementation

Technical Stack & REST API Architecture

Built with Node.js (v24), Express.js, AES-256-GCM Encryption, and Format-Preserving Tokenization (FPE).

Method API Endpoint Functionality
POST `/api/auth/employee-login` Authenticates bank security officers
POST `/api/auth/customer-temp-login` Authenticates customer temporary recovery session
GET `/api/sim-events/feed` Streams real-time SIM recycling queue
POST `/api/account/reregister-number` Updates primary number via Aadhaar eKYC
POST `/api/account/card-controls` Unblocks or emergency freezes cards
Slide 06 // Regulatory Compliance

Regulatory & Statutory Identity Compliance

🏛️ RBI Cyber Security Framework

Meets mandatory guidelines for rapid account isolation, multi-factor authentication, and proactive fraud containment.

🔐 PCI-DSS 4.0 Level 1

Replaces raw credit card PANs and PII with format-preserving surrogate tokens (`TOK-PAN-XXXX`) to remove database files from PCI audit scope.

🆔 UIDAI Aadhaar Vault

Queries internal bank Aadhaar Data Vault for alternate contacts under existing statutory identity verification authority.

📜 DPDP Act 2023 / GDPR

Enforces strict PII data minimization and automated session token self-destruction.
